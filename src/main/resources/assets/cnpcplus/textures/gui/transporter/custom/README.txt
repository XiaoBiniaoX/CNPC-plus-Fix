传送点图片目录 / Transport point images
=====================================

把 PNG 直接放进这个文件夹，就能在游戏里用"相对路径"引用，不需要上传、不需要重启：

    custom/example.png
    custom/传送门.png        （中文文件名也可以，路径会原样保留）

填写位置：NPC 高级设置 → 传送点 → 可视化编辑 → 选中"展示图片 / 图标" →
"图片路径"输入框里填上上面的相对路径，按回车（离开输入框）即可。

渲染规则
--------
* 相对路径会自动补全为  cnpcplus:textures/gui/transporter/<你填的路径>
* 也可以写完整命名空间路径，例如：mypack:textures/gui/transporter/portal.png
* 文件不存在时会保留上一次的图 / 显示默认图标，并在左下角给出提示。
* 换图：材质包里放同名同路径的文件覆盖即可，F3+T 重载资源后立即生效。

材质包写法（推荐给整合包作者）
------------------------------
    <材质包>/assets/cnpcplus/textures/gui/transporter/custom/portal.png
    <材质包>/pack.mcmeta

材质包优先级高于本模组自带的这张示例图。

注意
----
* 只支持 PNG；尺寸建议 ≤ 2048×2048。
* 服务端只保存"路径字符串"，所以客户端没装对应材质包时会退回默认图标，
  不会导致其他玩家掉线或报错。
